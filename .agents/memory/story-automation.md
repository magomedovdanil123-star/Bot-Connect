---
name: Story publishing mode
description: Manual story publishing rules and dormant automation safeguards.
---

Режим историй по умолчанию ручной: пользователь сам отправляет исходный сценарий и подтверждает запуск; бот не должен сам придумывать тему, запускать batch или публиковать без нажатия пользователя. Каждый выбранный канал получает отдельную уникальную версию, одно изображение на весь ролик и обязательный баннер.

**Why:** Пользователь хочет сам контролировать исходную историю и момент запуска, а автоматическая публикация могла создать нежелательный контент без подтверждения.

**How to apply:** Сохранять автоматизацию выключенной; если её код остаётся для будущего режима, отменённые batch не должны доходить до публикации. В ручном flow использовать исходный текст пользователя как основу, а AI — только для канал-специфичной уникализации и SEO. Длинную подготовку показывать одним обновляемым Telegram-сообщением с прогрессом каждого варианта.
