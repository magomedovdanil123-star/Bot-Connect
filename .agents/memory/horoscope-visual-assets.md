name: Horoscope visual asset library
description: Planned horoscope media library with sign-specific labeled images and reusable cosmic stock assets.
---

For each horoscope sign/channel, create and save a sign-specific image that includes the sign name and/or zodiac symbol in the artwork. Separately build a large varied library of space and cosmic stock photos and videos, preserving source, license, and attribution metadata, and store the assets in Supabase for reuse during video assembly.

**Why:** Horoscope videos need consistent recognizable sign branding while still having enough varied cosmic footage and imagery to avoid repetitive scenes.

**How to apply:** Keep sign artwork and generic cosmic stock assets as separate reusable media types. Validate each asset before saving, retain licensing metadata, and let the video planner select a diverse subset per horoscope instead of reusing one fixed background.
