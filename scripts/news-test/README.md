# Тест «Зверо-новости 2.0» (не для деплоя)

Демо-набор визуальных фишек новостей. В код бота пока не внедрён.
Что в нём:
- студия в цвет рубрики;
- окно с фото за ведущими;
- плашка-заголовок;
- вспышки папарацци, глитч и конфетти;
- наезд и резкий зум камеры;
- Крот плюётся кофе;
- реакции над головами.

Запуск:

    node scripts/news-test/run.mjs <папка> [секунды через запятую]

- Без секунд рендерит весь ролик в `<папка>/zveronews_test.mp4`.
- `VOICE=файл.wav` подмешивает озвучку.
- `MEDIA=media.json` подключает фото к новостям.
