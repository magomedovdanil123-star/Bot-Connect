# Motion Bot

Telegram-бот, который делает моушн-видео по сценарию: тёмная сетка, фиолетовый неон, кинетическая типографика, схемы, графики и счётчики. Формат 16:9, 1920×1080, 30 fps.

Нейросети не используются: сценарий разбирают правила (`src/planner.js`), и под каждую фразу подбирается одна из 28 анимаций (`src/engine/templates.js`). Кадры рисует Chromium, видео собирает ffmpeg. По желанию текст озвучивается через Lumean.

## Публикация на YouTube

После ролика бот показывает карточку публикации: SEO-название, описание с таймкодами глав, теги и хэштеги (`src/seo.js`, из текста сценария, без выдуманных фактов). Каналы отмечаются галочками (выбор запоминается), доступ — открытый / по ссылке / приватный, всё можно поправить кнопками «✏️».

Каналы берутся из проекта **Bot-Connect**: та же база (`youtube_connections`), тот же OAuth-клиент и ключ шифрования токенов — подключать каналы заново не нужно (`src/youtube.js`). Один раз нажмите «🔑 Подключить каналы из Bot-Connect» и пришлите одним сообщением из Replit → Secrets:

```
YOUTUBE_CLIENT_ID=…
YOUTUBE_CLIENT_SECRET=…
YOUTUBE_TOKEN_ENCRYPTION_KEY=…
SUPABASE_DB_PASSWORD=…
```

Бот сохранит их в `data/secrets.env` (права 600) и удалит сообщение из чата. Видео для публикации хранится 3 дня. Доступ по умолчанию — `YOUTUBE_DEFAULT_PRIVACY_STATUS` (иначе открытый).

## Режиссура: каждый ролик уникален

`src/director.js` по **seed** и истории прошлых роликов (`data/history.json`) выбирает визуальный почерк ролика:

| Измерение | Варианты |
| --- | --- |
| Акцент (неоновый, стиль канала един) | фиолетовый (чаще), циан, мятный, маджента, янтарный, электрик |
| Характер монтажа | кинетичный, чистый, цифровой, кинематографичный |
| Переходы | whip с motion blur, zoom-through, шторка с неоновым краем, iris-морфинг квадрат→круг, вертикальный push, вспышка, глитч/RGB, match-zoom, растворение |
| Камера | наезд, удар-наезд, отъезд, панорама, дрейф, статика + параллакс сетки и частиц |
| Заголовки | drop, rise, stretch, split, zoom, scramble |
| Монеты/тикеры | вращение, взрыв колец, световой блик, флип |
| Подписи | rise, blur, mask, pop, typewriter (длинные фразы прокручиваются) |
| Частицы / HUD / фон | пыль, искры, цифровые символы / рамка, минимал, бегущая строка тикеров / сетка, мелкая сетка, точки, кресты |
| Хук и финал | вспышка, глитч, zoom, шторка / схлопывание, iris, глитч, отъезд, линия |

Внутри ролика решения выбираются по смыслу: громкие сцены (заголовки, главы, «с X до Y») — вспышка/zoom и наезд камеры; данные — шторки и панорамы; две сцены с монетой подряд — match-переход; после громкой сцены — спокойная. Не больше двух «громких» сцен подряд, один переход не повторяется дважды подряд. На числах и названиях в момент произнесения — удар (тряска, вспышка, всплеск частиц) не чаще раза в 1.4 с. Рост/падение иногда показываются свечным графиком (без выдуманных цен).

Один и тот же проект с тем же seed воспроизводится 1:1 (кнопка «🔁 Пересобрать 1:1», озвучка берётся из проекта — Lumean повторно не платится). Кнопка «🎲 Новый визуальный стиль» — тот же сценарий с новым seed. Зафиксировать фирменный акцент: `STYLE_ACCENT=violet` в `.env`.

Музыка синтезируется под каждый ролик (без сэмплов и лицензий): темп и гармония от seed, аранжировка следует за напряжением сцен, музыка приседает под голос. Без озвучки склейки ставятся в бит. Движение построено по принципам из скилов motion-design: пружины с перелётом, упреждение, сжатие при приземлении, ступенчатое появление до 0.5 с, блик после появления, свечение неона (bloom). Новые сцены: сборка монеты из частиц (вход ролика), 3D-карусель монет (3+ проекта в фразе), гиперпрыжок (скорость).

## Звуковой дизайн

`src/sfx.js` — собственный синтез 17 видов звуков × 6 вариаций (whoosh, swoosh, sweep, impact, cinematic hit, sub-drop, click, tick, blip, ding, riser, glitch, shimmer, pop, tape-stop, reverse, air). Внешних файлов нет — лицензионных ограничений нет. Звуки привязаны к переходам, ударам, счётчикам, появлению элементов; перед громкой сценой после спокойной — riser. Плотность ограничена, одинаковые вариации подряд не повторяются. Голос выравнивается по громкости (−16 LUFS), шина SFX автоматически приглушается под голос (sidechain), финальный лимитер не даёт клиппинга.

## Синхронизация с озвучкой

Границы фраз берутся из субтитров Lumean (если шаблон их отдаёт), иначе — выравниванием по паузам: для каждой границы ищется пауза рядом с ожидаемой позицией (динамическое программирование), поэтому драматические паузы внутри фраз не сбивают монтаж. Слова внутри фразы привязываются к паузам на знаках препинания, анимации запускаются с упреждением 0.12 с, сцена появляется за 0.18 с до голоса. Длинный текст озвучивается несколькими заказами и склеивается.

## Как пользоваться

1. В боте выбери режим: **🐹 Хомяк-история** (комикс, хомяк проживает фразы) или **💜 Неон-инфографика** (без персонажей). Сценарий по теме — **✨ Сценарий по теме** (сначала рубрика, потом тема).
2. Пришли сценарий текстом или `.txt` файлом. На карточке сценария — переключатели: стиль, формат (16:9 / Shorts), озвучка, реклама.
3. Длинный сценарий — несколькими сообщениями подряд или `.txt`, затем «✅ Собрать ролик». Ограничений по длине нет.
4. Бот покажет прогресс и пришлёт MP4. Если ролик не помещается в 50 МБ без потери качества, он придёт частями.

Подсказки по сценарию — кнопка **ℹ️ Как писать сценарий** или команда `/help`.

## Как бот выбирает анимацию

| В тексте | Сцена |
| --- | --- |
| Короткая фраза («Давай разбираться.») | крупный кинетический заголовок с глитчем |
| «Но подожди.», «Стоп.» | пауза, тряска, заголовок |
| Вопросы | анкета с вопросами или крупный вопрос |
| «Первая история — …», «Вторая причина — …» | заставка главы с большой цифрой |
| Год (2011, 2027) | таймлайн |
| Число («5 миллионов») | счётчик |
| «с 8 до 200» | было → стало |
| «у X … 21, то у Y … 84» | сравнение полосами и множитель ×N |
| Два названия + «то», «тогда как», «против» | монеты друг против друга |
| Перечисление через запятую | схема со стрелками или сеть узлов |
| рост, ракета, иксы | график роста |
| падение, отставание, медвежий | график отставания |
| перевод, платёж | перевод от отправителя к получателю |
| приватность, анонимность | шифрование строк транзакций |
| работает, поддерживает | панель статуса сети |
| «между», «с одной стороны» | «два мира» |
| внимание, волна, хайп | волны вокруг монеты |
| «это не про X», «не означает, что X» | перечёркнутое слово |
| подписывайся | кнопка «Подписаться» с кликом |
| ссылка в шапке профиля | макет профиля со стрелкой |
| не финансовая рекомендация | предупреждение с чек-листом |
| всё остальное | карточки ключевых слов, монета с выносками или схема |

Названия латиницей (Bitcoin, ETF), числа и годы подсвечиваются в подписях автоматически. Похожие сцены не повторяются чаще раза в 4 фразы.

## Запуск на сервере (Docker — рекомендуется)

Нужен VPS: от 4 ядер и 4 ГБ RAM, Ubuntu 22.04 или 24.04. Минута видео рендерится примерно 4–5 минут на 4 ядрах.

```bash
# 1. Docker
curl -fsSL https://get.docker.com | sh

# 2. Код
git clone https://github.com/<you>/<repo>.git motion-bot && cd motion-bot

# 3. Настройки
cp .env.example .env
nano .env            # вставь BOT_TOKEN, свой id в ALLOWED_USERS, при желании LUMEAN_KEY и LUMEAN_TEMPLATE

# 4. Запуск (перезапускается сам после сбоев и перезагрузки)
docker compose up -d --build
docker compose logs -f   # «Бот @… запущен»
```

Свой Telegram id можно узнать так: напиши боту что угодно до того, как заполнишь `ALLOWED_USERS`, или спроси у @userinfobot.

## Запуск без Docker

```bash
sudo apt install -y ffmpeg
# Node.js 20+:
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo bash - && sudo apt install -y nodejs
npm install                        # заодно скачает Chromium для Playwright
npx playwright install-deps chromium
cp .env.example .env && nano .env
npm start
```

## Настройки (`.env`)

| Переменная | Зачем |
| --- | --- |
| `BOT_TOKEN` | токен от @BotFather, обязательно |
| `ALLOWED_USERS` | id или @username через запятую. Пусто = бот доступен всем, лучше так не делать |
| `LUMEAN_KEY`, `LUMEAN_TEMPLATE` | озвучка через Lumean по твоему шаблону; без них кнопка озвучки скрыта |
| `STYLE_ACCENT` | зафиксировать акцент (violet, cyan, mint, magenta, amber, electric) |
| `MAX_VIDEO_MB` | размер одной части видео, по умолчанию 48 |
| `MUSIC` | `0` — без музыкальной подложки (по умолчанию музыка есть) |
| `BRAND_NAME`, `BRAND_TAGLINE` | имя и слоган на заставке, в Shorts и на шапке (по умолчанию «ХОМЯК» / «ДЕНЬГИ БЕЗ ПАНИКИ») |
| `NO_IDENT` | `1` — без фирменной заставки в роликах с хомяком |
| `TELEGRAM_API_BASE` | свой адрес Bot API (прокси), если `api.telegram.org` недоступен с сервера |
| `STYLE_THEME` | `ink` — комикс-тема для всех роликов, `neon` — неон (по умолчанию: комикс, если в сценарии есть хомяк) |
| `ANTHROPIC_API_KEY`, `ANTHROPIC_BASE_URL` | генератор сценариев «✨ Сценарий по теме» (ключ можно прислать в бот; адрес посредника — если API недоступен из страны сервера) |
| `VOICESTUDIO_URL`, `VOICESTUDIO_TOKEN`, `VOICESTUDIO_VOICE`, `VOICESTUDIO_MODEL`, `VOICESTUDIO_SPEED` | озвучка своим клоном голоса из VoiceStudio на компьютере (подключение — командой /voicestudio в боте; если программа выключена — Lumean) |

**Клон голоса из записи:** команда `/clone` в боте → пришлите аудио (mp3/wav/голосовое, 15–60 с чистой речи). Бот вырежет лучший фрагмент 12–25 с по паузам, выровняет громкость, создаст в VoiceStudio профиль «Голос канала», сразу выберет его для озвучки и пришлёт пробную фразу. Образец хранится только в `data/voice/` (в git не попадает).

### Озвучка своим голосом прямо на сервере (без компьютера)

VoiceStudio можно запустить рядом с ботом — тогда озвучка работает как Lumean, круглосуточно:

```bash
cd ~/motion-bot && bash voice-server.sh
```

Скрипт проверит память (нужно ≥ 8 ГБ ОЗУ) и диск (≥ 15 ГБ), создаст ключ, пропишет `VOICESTUDIO_URL=http://voicestudio:3900` и запустит контейнер. Первый старт скачивает модели (~4 ГБ). Затем в боте: `/clone` → пришлите запись голоса. Клон создаётся один раз; образец хранится в `data/voice/reference.wav`, и если профиль в VoiceStudio пропадёт, бот пересоздаст его сам. Модели и профили лежат в `voicestudio-data/` и переживают обновления.

| `VOICE_PROVIDER` | `lumean` — всегда Lumean, даже если VoiceStudio подключён |
| `SCRIPT_MODEL` | модель генератора, по умолчанию `claude-opus-5-5` |
| `MUSIC_DB` | громкость музыки под голосом, дБ (по умолчанию -14) |

`.env` не попадает в git: токены храни только там.

## Озвучка

Бот отправляет в Lumean весь текст одним заказом и ставит между фразами бесплатные паузы `{{pause=0.8}}`. Потом по этим паузам в готовом аудио находит, где начинается каждая фраза, и подгоняет под них сцены и подписи. Формат субтитров Lumean знать не нужно.

## Структура

```
bot.js                 Telegram-бот (long polling, очередь рендера)
cli.js                 локальный запуск
src/planner.js         разбор сценария -> план сцен
src/make.js            сценарий -> озвучка -> план -> MP4
src/render.js          рендер кадров в Chromium + ffmpeg
src/voice.js           Lumean API и тайминги по паузам
src/engine/engine.js   примитивы: текст, блоки, линии, монеты, свечение
src/engine/templates.js 28 шаблонов сцен
src/engine/player.js   таймлайн, подписи, фон, HUD, переходы
src/engine/fonts/      Inter Display и DejaVu Sans Mono (свободные лицензии)
```

Чтобы добавить новую анимацию: напиши функцию в `templates.js` и правило в `classify()` в `planner.js`.


## Хомяк — талисман канала

Если в сценарии есть «Хомяк» (в любом падеже), ролик собирается в комикс-теме с талисманом: фирменная заставка с джинглом, локации по смыслу фраз (дом, офис, магазин, банк, биржа, улица, Луна), действия по глаголам (получает, платит, тратит, кэшбэк, копит, паникует, думает, колесо, спит на купюрах, изучает график, считает, не понимает, ракета), толпа хомяков, обращение к зрителю с наездом камеры, синхрон губ с озвучкой, звуки хомяка.

**Кинокамера.** В историях режиссёр ставит планы: общий на новом месте, наезд-удар на шоке, средний/крупный/голландский угол на эмоциях, проезд. Фон и передний план размыты (глубина резкости), свет меняется по времени суток и настроению.

**Паспорт серии.** У каждого ролика свой образ хомяка (костюм, худи, детектив, космонавт, спорт — подсказывает тема), время суток и погода. Принудительно: `HAMSTER_OUTFIT`, `EPISODE_TOD`.

**Кот-банкир** — антагонист: «Кот», «Кот-банкир» в сценарии. Действия: «забирает … рублей комиссии», «смеётся». В новые места за хомяком не ходит.

**Реклама.** Кнопка «🏷 Реклама» — задать предложение (название, ссылка, erid, рекламодатель, выгоды). В ролике с рекламой — сцена с картой и выгодами, «ссылка в описании», маркировка «Реклама. … erid» в кадре и в описании, ссылка с меткой ролика `subid`. Без erid рекламный ролик публиковать нельзя (38-ФЗ).

**Сайты в кадре.** Напишите в сценарии адрес сайта («Заходим на pampadu.ru и жмём регистрацию»): бот сам откроет сайт, снимет страницу, покажет её в окне браузера, прокрутит к кнопке-призыву (регистрация, «стать агентом», «начать»), наедет камерой и обведёт её маркером, а хомяк покажет лапкой. Снимки сохраняются в проекте. Если сайт не открылся — в окне будет его адрес.

Правила персонажей, камеры, рубрик и рекламы — в скилле `.claude/skills/hamster-director/SKILL.md`. Кадры без рендера: `node scripts/preview.mjs сценарий.txt seed папка 3,7.5,12`.

После ролика бот присылает 3 обложки (выбранная ставится на YouTube при публикации) и кнопку «📱 Shorts 9:16». Фирменные материалы (аватарка, шапка, стикеры): `node cli.js --brand папка`.
