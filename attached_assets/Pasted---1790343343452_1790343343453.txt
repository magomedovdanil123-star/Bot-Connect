СТРОГОЕ ПРАВИЛО ВЫПОЛНЕНИЯ ПРЕДЫДУЩЕГО ТЗ

Работай по предыдущему большому промпту ПО ПУНКТАМ и не пропускай требования.

1. Сначала полностью перечитай предыдущий промпт и составь внутренний checklist всех требований.

2. Не пытайся сразу сделать всё. Работай последовательно:
ТРЕБОВАНИЕ → ИЗМЕНЕНИЕ КОДА → ПРОВЕРКА → ТЕСТ → СЛЕДУЮЩЕЕ ТРЕБОВАНИЕ.

3. Нельзя считать задачу выполненной только потому, что:
- код компилируется;
- MP4 создаётся;
- сцены меняются;
- добавлен zoom;
- визуал "выглядит динамично".

Проверяй именно соответствие ТЗ.

4. После каждого крупного этапа проверяй:
- действительно ли функция подключена к рабочему pipeline;
- реально ли она работает при render;
- не является ли это просто заготовкой;
- не сломал ли ты существующие функции.

5. ОСОБЕННО ПРОВЕРЯЙ ГЛАВНОЕ ТРЕБОВАНИЕ:
динамика должна быть ВНУТРИ сцен.

Не:
СЦЕНА 1 → 5 секунд → СЦЕНА 2.

А:
объект → текст → стикер → стрелка → цифра → новый объект → смена позы → исчезновение → следующий объект.

То есть примерно каждые 1–3 секунды должен происходить новый визуальный акцент.

6. После реализации сделай тестовый ролик 30–35 секунд и проверь:
- 12–20+ visual beats;
- 25+ микро-анимационных событий;
- 4–6 смен позы ведущего;
- разные entrance/exit анимации;
- kinetic keywords;
- синхронизацию визуалов с речью;
- отсутствие длинных статичных участков;
- отсутствие ситуации, когда вся динамика создана только zoom/pan камеры.

7. После render НЕ просто скажи "готово".
Проверь фактический результат видео.

Если результат не соответствует ТЗ:
ИСПРАВЬ КОД → ПЕРЕРЕНДЕРИ → ПРОВЕРЬ СНОВА.

8. В конце обязательно перечитай предыдущий промпт ещё раз и сделай FINAL CHECK:
PASS / PARTIAL / NOT DONE по каждому основному требованию.

Если что-то пропущено — сначала исправь, потом заканчивай работу.

Главное:
НЕ ПОДМЕНЯЙ МОИ ТРЕБОВАНИЯ УПРОЩЁННЫМИ АНАЛОГАМИ.

Если я требую micro-beats — смена сцен не считается.
Если я требую sticker pop — обычный fade не считается.
Если я требую смену позы — zoom камеры не считается.
Если я требую kinetic text — обычные субтитры не считаются.

Твоя задача — не убедить меня, что всё сделано, а ФАКТИЧЕСКИ проверить, что оно сделано.
