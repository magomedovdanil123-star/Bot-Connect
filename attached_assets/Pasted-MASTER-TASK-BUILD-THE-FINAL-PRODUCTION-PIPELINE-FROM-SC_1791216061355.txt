ЭТАП 3 — СУБТИТРЫ
==================================================

Субтитры являются обязательной частью FINAL STYLE.

Не заменять их labels.

Не делать только:

MARKET CAP
ATH
7 DAY
MEASURED RISE

Это secondary information.

Главный subtitle должен отражать РЕАЛЬНУЮ РЕЧЬ.

Например диктор:

"Dogecoin вырос на 127 процентов."

На экране:

DOGECOIN ВЫРОС

127%

и одновременно:

animated chart.

Ключевые слова должны получать:

size
motion
accent color
punch
timing.

Subtitle должен знать:

voice timing
main visual
object bounds
safe zones.

Текст не должен закрывать:

лицо
logo
chart
главный объект
важную цифру.

==================================================
ЭТАП 4 — SEMANTIC VISUAL DIRECTOR
==================================================

Каждый сценарий должен сначала анализироваться по смыслу.

Для каждого фрагмента определить:

WHAT IS BEING SAID?

WHAT IS THE MOST IMPORTANT INFORMATION?

WHAT SHOULD THE VIEWER SEE?

WHAT SHOULD MOVE?

WHAT SHOULD BE LARGE?

WHAT SHOULD BE SMALL?

WHAT SHOULD TRANSITION INTO THE NEXT SCENE?

Пример:

"Dogecoin достиг исторического максимума."

→ ATH chart
→ $0.73
→ ATH marker
→ DOGE logo
→ kinetic subtitle
→ camera push
→ impact.

Не просто:

background + text.
