Наша цель — создать постоянный стандарт монтажа для всех будущих длинных финансовых и криптовалютных видео:

**быстрый → динамичный → визуально насыщенный → дорогой → аккуратный → синхронизированный с речью.**

### 2. KINETIC TYPOGRAPHY

Это одна из главных частей нового стиля.

Ключевые слова должны визуально выделяться автоматически.

Например:

«Bitcoin может изменить финансовую систему».

Система может определить:

**BITCOIN** — крупный текст + быстрый вход

**ИЗМЕНИТЬ** — другой цвет + punch-in

**ФИНАНСОВУЮ СИСТЕМУ** — последовательное появление

Нужны разные типы появления:

* fade
* scale-in
* pop
* slide-left
* slide-right
* slide-up
* slide-down
* fly-in
* bounce-in
* word-by-word
* letter-by-letter
* overshoot
* elastic
* blur-in
* masked reveal

Не нужно использовать все эффекты подряд.

**Выбор должен зависеть от смысла фразы.**

### 3. КЛЮЧЕВЫЕ СЛОВА

Создай систему автоматического определения акцентных слов.

Приоритет:

1. Названия криптовалют / компаний / проектов
2. Денежные значения
3. Проценты
4. Важные цифры
5. Сильные смысловые слова
6. Контрастные слова
7. Термины
8. Вопросы
9. Предупреждения
10. Итоговые выводы

Например:

«Проект потерял **87%** капитализации».

87% → огромная цифра + резкий punch-in + соответствующий визуальный акцент.

«Но есть одна **ПРОБЛЕМА**».

ПРОБЛЕМА → отдельный сильный текстовый акцент.

---

### 4. НЕ ДЕЛАЙ КАЖДОЕ СЛОВО КРИЧАЩИМ

Это очень важно.

Premium-стиль ≠ постоянный хаос.

Большая часть текста должна оставаться спокойной.

Акцентировать нужно только действительно важные слова.

Примерное соотношение:

**70% — clean / restrained**
**20% — dynamic**
**10% — extreme impact**

То есть зритель должен чувствовать динамику, но не устать от неё.

---

### 5. FAST CUT

Добавь возможность менять визуальные блоки внутри одной фразы.

Например:

VOICE:
«Bitcoin появился как альтернатива традиционной финансовой системе».

Вместо одной картинки:

Bitcoin logo
→ blockchain animation
→ old financial system
→ bank footage
→ Bitcoin
→ крупная фраза
→ следующий блок.

Длина визуальных фрагментов должна зависеть от темпа речи и важности информации.

Не использовать постоянный одинаковый интервал типа «новый кадр каждые 3 секунды».

---

### 6. PUNCH-IN

Добавь события:

NORMAL
→ PUNCH IN
→ NORMAL

При произнесении ключевого слова.

Например:

«Именно здесь **TON** становится интересным».

На TON:

scale 100%
→ 115–125%
→ возврат.

Движение должно быть быстрым и аккуратным.
