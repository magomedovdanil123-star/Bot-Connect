# AI CONTENT FACTORY — FULL AUTO VIDEO PIPELINE

Теперь перестань делать отдельные модули по одному.

Моя конечная цель — простая:

Я ввожу ТОЛЬКО ТЕМУ.

Например:

"Курьер получил странный заказ в 2 часа ночи"

После этого AI Content Factory автоматически должна сделать ВСЁ:

ТЕМА
↓
СЦЕНАРИЙ
↓
СЦЕНЫ
↓
ИЗОБРАЖЕНИЯ
↓
AI ОЗВУЧКА ELEVENLABS
↓
МУЗЫКА
↓
ЗВУКОВЫЕ ЭФФЕКТЫ
↓
ЛЁГКИЙ МОНТАЖ
↓
СУБТИТРЫ
↓
ГОТОВЫЙ MP4
↓
DOWNLOAD

Пользователь не должен вручную собирать проект из отдельных частей.

==================================================
ГЛАВНЫЙ ПРИНЦИП
==================================================

Сделай единый:

POST /api/projects/{id}/generate-video

который запускает весь pipeline.

Также во frontend должна быть одна главная кнопка:

🎬 СОЗДАТЬ ВИДЕО

Пользователь вводит:

Тема:
[________________________]

Дополнительно можно выбрать:

Формат: 9:16
Длительность: 30 / 60 / 90 секунд
Стиль: Cinematic / Realistic / Documentary / etc.
Тон: Dramatic / Funny / Emotional / Suspense / etc.

Но даже если пользователь ничего не выбрал — система должна использовать разумные defaults.

==================================================
1. ГЕНЕРАЦИЯ СЦЕНАРИЯ
==================================================

AI получает тему и самостоятельно создаёт сценарий.

Сценарий должен быть рассчитан на выбранную длительность.

Разделить сценарий на сцены.

Каждая сцена должна иметь:

scene_id
voice_text
visual_description
image_prompt
mood
emotion
duration_estimate

Использовать существующую OpenRouter-инфраструктуру.

Не ломать существующую генерацию сценариев.

==================================================
2. ИЗОБРАЖЕНИЯ
==================================================

Для каждой сцены автоматически создать изображение.

Использовать существующую image generation интеграцию.

По умолчанию:

9:16

Изображение должно соответствовать:

- сценарию;
- visual_description;
- image_prompt;
- стилю;
- атмосфере;
- персонажу.

Если включён CharacterProfile:

обязательно передавать canonical character description в каждый image prompt.

Для каждой сцены:

scene 1 → image
scene 2 → image
scene 3 → image
...

Не требовать от пользователя вручную нажимать "создать изображение" для каждой сцены.

==================================================
3. ELEVENLABS
==================================================

Использовать уже реализованную ElevenLabs интеграцию.

Автоматически:

- выбрать настроенный voice;
- использовать настроенную модель;
- разделить сценарий по сценам;
- создать MP3 для каждой сцены;
- создать full voice;
- получить duration;
- создать timeline.

Использовать:

ELEVENLABS_API_KEY
ELEVENLABS_VOICE_ID
ELEVENLABS_MODEL_ID

Если ключ отсутствует — pipeline должен остановиться с понятной ошибкой.

НЕ симулировать успешную генерацию.

==================================================
4. МУЗЫКА
==================================================

AI автоматически анализирует сценарий.

Определяет:

mood
energy
tension
style

и подбирает подходящую музыку.

Например:

dramatic → cinematic
suspense → suspense
motivational → energetic
calm → ambient
dark → dark cinematic
funny → light/comedy

Пользователь НЕ обязан выбирать музыку вручную.

Музыка автоматически:

- подгоняется под длину ролика;
- trim/loop;
- fade in;
- fade out;
- регулируется по громкости.

По умолчанию музыка должна быть тихой и не мешать голосу.

==================================================
5. SOUND EFFECTS
==================================================

AI анализирует каждую сцену и автоматически определяет, нужны ли SFX.

Например:

"Телефон завибрировал"
→ phone vibration

"Он открыл дверь"
→ door open

"Начался дождь"
→ rain ambience

"Он побежал"
→ footsteps

"Раздался гром"
→ thunder

Не добавлять эффекты на каждое предложение.

Только там, где они реально усиливают сцену.

Максимум примерно 1–3 важных эффекта на сцену.

SFX автоматически ставятся на timeline.

==================================================
6. АВТОМАТИЧЕСКИЙ SOUND DESIGN
==================================================

Создать:

Auto Sound Design.

AI должен автоматически определить:

- музыку;
- настроение;
- интенсивность;
- SFX;
- ambience;
- timing.

Пользователь не должен вручную расставлять звуки.

==================================================
7. ДУКИНГ
==================================================

Когда говорит ElevenLabs:

музыка автоматически становится тише.

Когда речь заканчивается:

музыка плавно возвращается.

Голос всегда главный.

Например:

voice → music 5–8%
no voice → music 10–15%

Значения можно адаптировать автоматически.

SFX тоже не должны перекрывать голос.

==================================================
8. СУБТИТРЫ
==================================================

Автоматически создать субтитры из voice timeline.

Не требовать ручного ввода.

Субтитры должны:

- совпадать с речью;
- иметь таймкоды;
- разбиваться на короткие читаемые фразы;
- быть хорошо видны на вертикальном видео.

По умолчанию:

- белый текст;
- контрастная обводка/тень;
- нижняя/центральная безопасная область;
- размер, подходящий для телефона.

Добавить лёгкую анимацию появления, если это возможно без усложнения render pipeline.

==================================================

==================================================

Создать единый timeline:

IMAGE
VOICE
MUSIC

SUBTITLES

Все элементы должны быть синхронизированы.

Пример:

00:00–00:05
Image 1
Voice 1
Music
Ambience

00:05–00:11
Image 2
Voice 2
Music
Phone vibration

00:11–00:17
Image 3
Voice 3
Music
Door sound

и т.д.

==================================================
10. ЛЁГКИЙ МОНТАЖ
==================================================

Не создавай сложный видеоредактор.

Нужен автоматический лёгкий монтаж.

Для изображений использовать:

- плавные zoom in;
- zoom out;
- pan;
- лёгкие transitions;
- fade;
- cinematic movement.

Каждая сцена должна ощущаться как небольшой видеокадр, а не просто неподвижная картинка.

Не перегружать эффектами.

==================================================
14. ОШИБКИ
==================================================

Если одна сцена изображения упала:

не обязательно пересобирать всё с нуля.

Повторить failed stage.

Если ElevenLabs упал:

показать ошибку.

Если музыка недоступна:

pipeline может продолжить без музыки, если это разрешено.

Если SFX недоступен:

pipeline может продолжить без SFX.

Если subtitles failed:

показать ошибку и предложить повторить.

Если video rendering failed:

сохранить все предыдущие результаты и позволить повторить render.

Не терять уже созданные изображения и аудио.
