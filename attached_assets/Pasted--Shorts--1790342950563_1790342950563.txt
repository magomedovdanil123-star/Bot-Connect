ВАЖНО.

Нужно полностью пересмотреть текущую логику анимации Shorts.

Я посмотрел текущий результат 02-stock.mp4.

Сейчас ролик технически выглядит аккуратно, но НЕ соответствует референсу по динамике.

Главная проблема:

Текущая логика воспринимает "смену сцены" как достаточную анимацию.

Это НЕПРАВИЛЬНО.

Мне не нужны просто разные красивые экраны, которые меняются каждые 5–8 секунд.

Мне нужно воспроизвести саму МЕХАНИКУ РЕФЕРЕНСА:

РЕЧЬ → маленькое визуальное действие → маленькое визуальное действие → маленькое визуальное действие → смена позы ведущего → новый объект → текст → стикер → новый объект → следующий смысловой блок.

То есть динамика должна происходить ВНУТРИ одной сцены, а не только МЕЖДУ сценами.

Не считать смену сцены = динамика.

Не считать zoom = динамика.

Не считать появление новой большой карточки = динамика.

Каждые 1–3 секунды зритель должен получать новый визуальный стимул.

ВАЖНО:

Каждый ролик должен состоять из:

LAYER 1 — ВЕДУЩИЙ

5.0 сек — ведущий меняет позу

Это и есть нужная динамика.

5.0–6.0

==================================================
4. СКОРОСТЬ
==================================================

Это КРИТИЧНО.

Сейчас элементы слишком долго находятся на экране без изменений.

Не нужно держать один объект статично 5–8 секунд.

Средняя длительность одного визуального акцента:

0.8–2.5 секунды.

Некоторые крупные элементы могут жить 3–4 секунды.

Но даже если объект остаётся на экране дольше:

ОН ДОЛЖЕН ПРОДОЛЖАТЬ ЖИТЬ.

Например:

появился график

→ через 1 сек подсветилась линия

→ ещё через 0.8 сек появилась стрелка

→ ещё через 0.7 сек выделилась цена

→ ещё через 1 сек появился label

То есть объект не должен быть мёртвым.
