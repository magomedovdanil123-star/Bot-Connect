Этап 3 — профессиональная AI-озвучка через ElevenLabs

Продолжай разработку существующего проекта AI Content Factory.

На предыдущих этапах уже реализованы:

Тема → сценарий → сцены → изображения

Теперь реализуй полноценный модуль:

Сценарий → ElevenLabs → озвучка → аудиосегменты → единая аудиодорожка

⚠️ Основной и обязательный TTS-провайдер — ElevenLabs.

Не подключай другой TTS вместо ElevenLabs.

Не реализовывай пока музыку и финальную сборку видео — это следующие этапы.

⸻

1. ElevenLabs

Интегрируй официальный API ElevenLabs.

API key хранить только в environment variables:

ELEVENLABS_API_KEY
ELEVENLABS_VOICE_ID
ELEVENLABS_MODEL_ID

Никаких ключей в frontend, GitHub, базе данных или исходном коде.

⸻

2. Выбор модели ElevenLabs

Архитектура должна позволять менять модель через ENV:

ELEVENLABS_MODEL_ID

Если конкретная модель не указана — используй актуальную модель ElevenLabs, доступную для выбранного API и русского языка.

Не хардкодь название модели там, где оно должно задаваться конфигурацией.

⸻

3. Выбор голоса

В интерфейсе сделать раздел:

🎙️ Голос ElevenLabs

Пользователь должен видеть доступные голоса ElevenLabs.

Добавь получение списка голосов через API ElevenLabs.

Показывать:

* имя;
* voice ID;
* описание;
* пол, если предоставляется API;
* язык/акцент, если доступен;
* preview, если доступен.

Кнопки:

▶ Прослушать

Выбрать

⸻

4. Кэширование голосов

Не запрашивать список голосов ElevenLabs при каждом открытии страницы.

Сделать кэш.

Например:

GET /api/voices

Backend получает список ElevenLabs и кэширует его.

Добавить возможность обновить список:

🔄 Обновить голоса

⸻

5. Настройки озвучки

Создай интерфейс:

🎙️ Озвучка ElevenLabs
Голос:
[ выбранный голос ]
Модель:
[ модель ]
Скорость:
0.8x — 1.2x
Стабильность:
[ slider ]
Similarity:
[ slider ]
Style:
[ slider ]
Speaker Boost:
ON/OFF

Используй только те параметры, которые реально поддерживает выбранная модель/API ElevenLabs.

Не отправляй в ElevenLabs параметры, которых нет у конкретной модели.

⸻

6. Русский язык

Основной сценарий проекта — русский язык.

При генерации учитывать:

language = ru

Если ElevenLabs определяет язык автоматически — не ломай автоматическое определение.

Главное требование:

русская речь должна звучать естественно, без искусственного иностранного акцента.

⸻

7. Стиль озвучки

В AI Content Factory пользователь выбирает:

Natural
Storytelling
Cinematic
Dramatic
Advertising
News
Calm
Energetic

Эти настройки должны преобразовываться в параметры ElevenLabs там, где это поддерживается.

Например:

Dramatic
→ более эмоциональная подача
Calm
→ спокойная подача
Advertising
→ энергичная коммерческая подача
Storytelling
→ естественная повествовательная подача

Не пытайся менять голос искусственными эффектами после генерации, если ElevenLabs позволяет решить это непосредственно через параметры модели.

⸻

8. Обработка сценария

После генерации сценария AI должен разделить его на сцены.

Например:

Сцена 1
Сегодня я расскажу вам историю...
Сцена 2
Всё началось поздним вечером...
Сцена 3
Но следующий заказ полностью изменил ситуацию...

Для каждой сцены создавать отдельный TTS-файл.

⸻

9. Сегментация текста

Не отправлять в ElevenLabs огромный текст целиком, если это может привести к проблемам с лимитами или управлением таймингом.

Разбивать текст на логические части.

Каждая сцена должна иметь:

scene_id
text
audio_id
duration
start_time
end_time

⸻

10. Паузы

Учитывай естественные паузы.

Например:

.
...
—

и переходы между сценами.

Если выбранная модель ElevenLabs поддерживает SSML/паузы в соответствующем формате — использовать поддерживаемый механизм.

Если нет — реализовать паузы на этапе последующей обработки аудио.

Не добавлять паузу после каждого предложения механически.

⸻

11. ElevenLabs API Service

Создай:

audio_generation/
├── __init__.py
├── service.py
├── elevenlabs_client.py
├── text_processor.py
├── timeline.py
├── schemas.py
├── models.py
└── utils.py

Основной клиент:

class ElevenLabsClient:
    async def generate_speech(
        self,
        text: str,
        voice_id: str,
        model_id: str,
        settings: dict
    ):
        ...

Вся работа с ElevenLabs API должна находиться внутри этого слоя.

Не смешивать HTTP-запросы ElevenLabs с бизнес-логикой проекта.

⸻

14. Отдельные аудиофайлы

Для каждой сцены:

voice/
├── scene_001.mp3
├── scene_002.mp3
├── scene_003.mp3
├── scene_004.mp3
└── full_voice.mp3

Формат можно привести к единому стандарту через FFmpeg, если это требуется.

⸻

15. Full Voice

После генерации всех сцен создать:

full_voice.mp3

Он должен быть собран из всех сцен в правильном порядке.

Учитывать:

* паузы;
* порядок сцен;
* длительность;
* отсутствие обрывов.

⸻

16. Timeline

После генерации сохранить таймлайн.

Пример:

Scene 1
00:00.000 → 00:04.820
Scene 2
00:04.820 → 00:09.430
Scene 3
00:09.430 → 00:15.120

Именно этот timeline в дальнейшем будет использоваться для синхронизации изображений и видео.

⸻

17. API

Добавить:

GET  /api/voices
POST /api/voices/refresh
POST /api/projects/{project_id}/voice/generate
GET  /api/projects/{project_id}/voice
GET  /api/voice/{voice_id}
GET  /api/voice/{voice_id}/status
POST /api/voice/{voice_id}/regenerate
POST /api/voice/{voice_id}/activate
DELETE /api/voice/{voice_id}

Все API должны использовать существующую систему авторизации.

⸻

18. Асинхронная генерация

Не держать HTTP-запрос открытым во время генерации ElevenLabs.

Использовать существующую систему background jobs проекта.

Статусы:

pending
processing
completed
failed

Frontend показывает:

🎙️ Генерация озвучки
Сцена 1 ✅
Сцена 2 ✅
Сцена 3 ⏳
Сцена 4 ⏳
Готово: 2/4

⸻

20. Проверка ElevenLabs API

При запуске проекта добавить понятную проверку конфигурации.

Если:

ELEVENLABS_API_KEY

не указан:

показывать:

❌ ElevenLabs API key не настроен.
Добавьте ELEVENLABS_API_KEY в Secrets / Environment Variables Replit.

Не выдавать ложный статус completed.

⸻

21. Replit Secrets

В документации проекта указать:

ELEVENLABS_API_KEY=...
ELEVENLABS_VOICE_ID=...
ELEVENLABS_MODEL_ID=...

Значения ключей пользователь добавляет самостоятельно через Replit Secrets.

Никогда не выводить значение API key в логах.

⸻

22. Обработка ошибок ElevenLabs

Обработать:

* invalid API key;
* insufficient credits;
* rate limit;
* timeout;
* invalid voice ID;
* invalid model ID;
* text too long;
* API unavailable.

Показывать пользователю нормальное сообщение.

Например:

❌ ElevenLabs отклонил запрос.
Проверьте:
• API key
• выбранный голос
• доступность модели
• лимит аккаунта ElevenLabs

Техническую ошибку сохранить в backend logs.

Секретные данные в ошибку не включать.

⸻
