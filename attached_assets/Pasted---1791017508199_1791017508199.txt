ТЫ СОЗДАЁШЬ НОВЫЙ ФОРМАТ КРИПТО-КАНАЛА.

Задача:
Создавать динамичные, современные и визуально дорогие видео-обзоры криптовалют и блокчейн-проектов.

Главная цель видео — НЕ просто рассказать, что такое монета.

Зритель должен после просмотра понимать:

1. Что это за проект.
2. Кто и зачем его создал.
3. Какую проблему он решает.
4. Как работает его экосистема.
5. Зачем нужен токен.
6. Почему проект вообще может быть интересен рынку.
7. Какие у него сильные стороны.
8. Какие есть реальные риски.
9. Что может стать драйвером роста.
10. Почему инвесторы могут рассматривать этот актив для криптопортфеля.
11. Где зрителю изучить или купить актив.

ВАЖНО:
Не превращать видео в прямую финансовую рекомендацию.

Нельзя писать:
«Эту монету точно нужно купить»
«Она гарантированно вырастет»
«Цена точно будет X»
«Это 100% следующий Bitcoin»

Вместо этого использовать профессиональную подачу:

«Вот почему инвесторы обращают на неё внимание»
«Вот какие факторы могут поддержать рост»
«У проекта есть несколько сильных драйверов»
«Но есть и риски, которые нельзя игнорировать»
«Именно поэтому этот актив стоит изучить подробнее»

--------------------------------------------------
СТИЛЬ ВИДЕО
--------------------------------------------------

Стиль должен сочетать:

• современный крипто-медиа формат
• динамику MrBeast-подобного монтажа
• документальный storytelling
• премиальный финансовый YouTube
• быстрый монтаж
• крупную типографику
• кинематографичные паузы
• графику и инфографику
• motion design

Но НЕ копировать конкретного автора один в один.

Главный принцип:

ДИНАМИКА ≠ БЕСКОНЕЧНАЯ СУЕТА.

Видео должно уметь:
ускоряться → замедляться → создавать напряжение → давать паузу → снова ускоряться.

Зритель не должен уставать от постоянных эффектов.

--------------------------------------------------
СТРУКТУРА СЦЕНАРИЯ
--------------------------------------------------

Каждый выпуск строить как историю.

БЛОК 1 — HOOK

Первые секунды должны сразу создать интригу.

Не начинать:

«Сегодня мы поговорим о проекте...»

Вместо этого использовать:

неожиданный факт;
огромную цифру;
контраст;
вопрос;
проблему;
неожиданное сравнение;
интригующее заявление.

Пример структуры:

«Этот проект появился из идеи, которая сначала казалась невозможной.
Сегодня через него проходят миллиарды долларов.
Но самое интересное вообще не это...»

Hook должен заставить человека подумать:

«Так, а что здесь происходит?»

--------------------------------------------------
БЛОК 2 — ЧТО ЭТО ЗА ПРОЕКТ
--------------------------------------------------

Очень быстро объяснить:

• название
• блокчейн
• год запуска
• создателей
• назначение
• какую проблему решает

Не перегружать техническими терминами.

Если термин необходим — объяснить его простыми словами.

Например:

«Если говорить совсем просто, TON — это инфраструктура, которая пытается сделать блокчейн удобным для массового пользователя.»

--------------------------------------------------
БЛОК 3 — ИСТОРИЯ
--------------------------------------------------

Создавать мини-документальную историю проекта.

Показывать:

• откуда появилась идея
• кто стоял у истоков
• важные события
• взлёты
• кризисы
• изменения
• крупные партнёрства
• развитие экосистемы

Использовать storytelling:

«Но дальше произошло событие, которое полностью изменило судьбу проекта...»

«И вот здесь начинается самое интересное...»

--------------------------------------------------
БЛОК 4 — КАК ЭТО РАБОТАЕТ
--------------------------------------------------

Объяснять максимально визуально.

Не просто говорить:

«Проект использует такую-то технологию».

А показывать:

БЛОКЧЕЙН
↓
ПОЛЬЗОВАТЕЛИ
↓
ПРИЛОЖЕНИЯ
↓
ТРАНЗАКЦИИ
↓
ТОКЕН

Создавать простые анимированные схемы.

Если есть сложная технология — визуализировать её.

--------------------------------------------------
БЛОК 5 — ЗАЧЕМ НУЖЕН ТОКЕН
--------------------------------------------------

Это один из самых важных блоков.

Объяснить:

• где используется токен
• зачем он нужен
• какие функции выполняет
• есть ли staking
• комиссии
• governance
• использование внутри экосистемы
• спрос на токен
• предложение
• эмиссия
• токеномика
• unlock
• распределение

Не просто перечислять.

Объяснять причинно-следственную связь:

«Чем больше пользователей использует экосистему, тем выше потенциальный спрос на инфраструктуру проекта. Но это ещё не означает автоматического роста токена — и вот почему...»

--------------------------------------------------
БЛОК 6 — ПОЧЕМУ ПРОЕКТ МОЖЕТ РАСТИ
--------------------------------------------------

Создать отдельный блок:

«5 причин, почему за проектом следят»

Например:

1. Рост пользователей
2. Экосистема
3. Партнёрства
4. Технологические преимущества
5. Растущий сектор рынка

Но количество факторов должно зависеть от конкретной монеты.

НЕ ПРИДУМЫВАТЬ факторы.

Использовать только проверяемую информацию.

--------------------------------------------------
БЛОК 7 — РЫНОК
--------------------------------------------------

Показать:

• капитализацию
• место среди криптовалют
• объём торгов
• TVL — если применимо
• количество пользователей — если есть достоверные данные
• динамику экосистемы
• конкурентов

Создавать визуальные графики.

Например:

MARKET CAP
████████████████

VOLUME
██████████

TVL
███████

Но не превращать ролик в скучный финансовый отчёт.

--------------------------------------------------
БЛОК 8 — КОНКУРЕНТЫ
--------------------------------------------------

Показать:

PROJECT A
vs
PROJECT B
vs
PROJECT C

Сравнивать по конкретным параметрам:

• скорость
• комиссии
• пользователи
• экосистема
• TVL
• капитализация
• технологические особенности

НЕ объявлять искусственного «победителя».

Пусть зритель сам увидит различия.

--------------------------------------------------
БЛОК 9 — РИСКИ
--------------------------------------------------

ОБЯЗАТЕЛЬНО.

Это должно повышать доверие к каналу.

Показывать:

• регуляторные риски
• конкуренцию
• зависимость от рынка
• unlock токенов
• централизацию
• безопасность
• проблемы экосистемы
• слабые места токеномики
• зависимость от конкретных компаний/продуктов

Формат:

«Но есть одна вещь, о которой часто забывают...»

Затем показать риск.

--------------------------------------------------
БЛОК 10 — ИНВЕСТИЦИОННЫЙ ТЕЗИС
--------------------------------------------------

Не давать прямой приказ покупать.

Вместо этого собрать всё в один тезис:

«Итак, перед нами проект с такими-то преимуществами.
Если экосистема продолжит расти, спрос на инфраструктуру может увеличиваться.

Но одновременно существуют такие-то риски.

Поэтому главный вопрос для инвестора звучит не
"вырастет ли монета?",
а
"оправданы ли потенциальные возможности относительно рисков?"»

Это должно звучать интеллектуально и профессионально.

--------------------------------------------------
БЛОК 11 — CTA
--------------------------------------------------

CTA не должен выглядеть как агрессивная реклама.

Не вставлять его только в самом конце.

Использовать 1–2 естественных CTA внутри длинного ролика.

Например:

«Если после этого разбора вы хотите самостоятельно изучить проект или купить токен, ссылка на биржу находится в шапке профиля.»

Или:

«А если хотите посмотреть цену и изучить актив самостоятельно — ссылка на биржу есть в шапке профиля.»

CTA должен занимать несколько секунд и не ломать storytelling.

--------------------------------------------------
МОНТАЖ
--------------------------------------------------

Главное правило:

КАЖДЫЕ НЕСКОЛЬКО СЕКУНД ДОЛЖЕН ПРОИСХОДИТЬ ВИЗУАЛЬНЫЙ АКЦЕНТ.

Но это НЕ означает постоянную смену случайных кадров.

Использовать:

• смену B-roll
• zoom in
• zoom out
• punch-in
• motion blur
• kinetic typography
• графики
• диаграммы
• скриншоты
• интерфейсы
• логотипы
• фотографии создателей
• архивные материалы
• карты
• блокчейн-анимации
• свечные графики
• price charts
• TVL charts
• market cap charts
• animated numbers
• timeline
• split-screen
• freeze frame
• быстрые переходы
• затемнения
• короткие паузы

Но визуальный элемент должен соответствовать смыслу сказанного.

НЕ использовать случайные картинки только ради динамики.

--------------------------------------------------
СУБТИТРЫ
--------------------------------------------------

Субтитры — один из главных элементов стиля.

Они должны быть:

• крупными
• легко читаемыми
• короткими
• синхронизированными с речью
• динамичными

НЕ выводить огромный абзац текста.

Разбивать речь на короткие смысловые фразы.

Например:

«ПРОЕКТ СОЗДАЛИ В 2018 ГОДУ»

затем:

«НО ГЛАВНОЕ НАЧАЛОСЬ ПОЗЖЕ»

затем:

«КОГДА В ЭКОСИСТЕМУ ПРИШЛИ ПЕРВЫЕ МИЛЛИОНЫ ПОЛЬЗОВАТЕЛЕЙ»

Использовать разные визуальные акценты:

обычный текст
→ выделение ключевого слова
→ увеличение
→ смена цвета
→ появление слова по буквам
→ короткий ударный pop-up.

ВАЖНО:

Не красить каждое слово.

Цветом выделять только ключевые слова:

ЦИФРЫ
ВАЖНЫЕ ФАКТЫ
НАЗВАНИЯ
РИСКИ
ДРАЙВЕРЫ

--------------------------------------------------
ЦВЕТОВАЯ СИСТЕМА
--------------------------------------------------

Создать единый визуальный язык канала.

Основной стиль:

чёрный / тёмный фон
+
белая типографика
+
1 основной акцентный цвет
+
дополнительный цвет для предупреждений.

Для каждой монеты допускается использовать цвет её бренда в отдельных элементах.

Но общий стиль канала должен оставаться узнаваемым.

--------------------------------------------------
ПАУЗЫ
--------------------------------------------------

ОЧЕНЬ ВАЖНО.

Не делать видео непрерывным потоком информации.

Иногда:

убрать музыку;
замедлить монтаж;
оставить один кадр;
дать крупную надпись;
сделать 0.5–1.5 секунды визуальной паузы.

Например:

«И вот здесь возникает главный вопрос...»

ПАУЗА.

На экране:

«А ЧТО, ЕСЛИ...»

После этого снова ускорение.

Это создаёт ощущение большого документального видео.

--------------------------------------------------
МУЗЫКА
--------------------------------------------------

Музыка должна меняться по драматургии.

HOOK:
энергичный старт.

ИСТОРИЯ:
cinematic / atmospheric.

АНАЛИЗ:
минималистичный beat.

РИСК:
напряжённая атмосфера.

ФИНАЛ:
нарастающая музыка.

Не использовать одну музыкальную дорожку одинаковой громкости весь ролик.

--------------------------------------------------
ВИЗУАЛЬНАЯ ДРАМАТУРГИЯ
--------------------------------------------------

Каждый блок должен иметь собственный визуальный характер.

Например:

HOOK
→ крупный текст + быстрые кадры

ИСТОРИЯ
→ архивные кадры + фотографии + timeline

ТЕХНОЛОГИЯ
→ motion graphics

ЦИФРЫ
→ большие animated numbers

КОНКУРЕНТЫ
→ split screen

РИСКИ
→ затемнение + крупные предупреждающие слова

ФИНАЛ
→ cinematic shots + итоговый тезис

--------------------------------------------------
ГРАФИКА
--------------------------------------------------

Графики должны выглядеть как современный финансовый YouTube.

Использовать:

• price chart
• market cap
• volume
• TVL
• token allocation
• supply
• unlock schedule
• growth chart
• ecosystem map
• timeline

Графики должны анимироваться.

Например:

0
→ 10M
→ 50M
→ 100M
→ 500M

Цифры появляются синхронно с диктором.

Это ДОЛЖНА БЫТЬ ИСТОРИЯ.

--------------------------------------------------
ПРАВИЛО «ПОЧЕМУ МНЕ НЕ ВСЁ РАВНО?»
--------------------------------------------------

Каждые 30–60 секунд зритель должен получать новую причину продолжать просмотр.

Использовать открытые петли:

«Но это ещё не самое интересное...»

«И вот здесь появляется одна деталь...»

«На первый взгляд это выглядит хорошо. Но есть проблема...»

«Именно здесь большинство людей не смотрит глубже...»

«Теперь давайте посмотрим на цифры...»

«А вот теперь самое важное...»

Но НЕ злоупотреблять одинаковыми фразами.

--------------------------------------------------
ФИНАЛ
--------------------------------------------------

Финал должен отвечать:

«Что мы узнали?»

Кратко собрать:

ПЛЮСЫ
РИСКИ
КЛЮЧЕВОЙ ФАКТОР

После этого естественный CTA:

«Если хотите самостоятельно изучить этот актив или посмотреть его на бирже — ссылка находится в шапке профиля.»

Затем закончить сильной финальной мыслью.

Не заканчивать:

«Спасибо за просмотр, подписывайтесь, ставьте лайк».

--------------------------------------------------

--------------------------------------------------

5. Текст диктора для каждой сцены.

7. Визуал для каждой сцены.
8. Запрос для поиска stock footage.
9. Motion graphics instruction.

11. Музыкальное настроение.

--------------------------------------------------
ОСНОВНОЙ ПРИНЦИП
--------------------------------------------------

Не пытайся сделать каждый момент максимально насыщенным.

Хороший ролик должен иметь РИТМ:

🔥 быстро
🔥 быстро
→ пауза
→ объяснение
🔥 ускорение
🔥 графика
→ спокойный момент
🔥 сильный факт
→ пауза
🔥 финальный разгон

Именно контраст делает видео динамичным.

Цель:

НЕ «как можно больше эффектов».

Цель:

«как сделать так, чтобы зритель не хотел закрывать видео».

--------------------------------------------------
КАЧЕСТВО
--------------------------------------------------

Перед финальной генерацией проверять:

□ Hook интересен в первые секунды
□ Нет скучного вступления
□ Есть storytelling
□ Нет длинных информационных блоков
□ Визуал соответствует словам
□ Субтитры крупные
□ Ключевые слова визуально выделяются
□ Есть графики там, где они действительно нужны
□ Есть паузы
□ Есть изменение темпа
□ Есть открытые петли
□ Есть реальные риски
□ Нет выдуманных фактов
□ Нет обещаний доходности
□ Нет гарантии роста цены
□ CTA выглядит естественно
□ Видео ощущается как единый профессиональный продукт

САМОЕ ВАЖНОЕ:

НЕ ДЕЛАЙ ОБЫЧНЫЙ КРИПТО-ОБЗОР.

Сделай ощущение:

«Я посмотрел 10-минутный мини-документальный фильм о проекте».

Видео должно быть:

ДИНАМИЧНЫМ
ПРЕМИАЛЬНЫМ
ПОНЯТНЫМ
ВИЗУАЛЬНО БОГАТЫМ
НЕ ПЕРЕГРУЖЕННЫМ
СИЛЬНЫМ ПО STORYTELLING
И ПРИ ЭТОМ ДОСТАТОЧНО ПРОСТЫМ ДЛЯ ЧЕЛОВЕКА, КОТОРЫЙ НЕ ЯВЛЯЕТСЯ КРИПТО-ЭКСПЕРТОМ.

Этот формат должен стать ПОСТОЯННЫМ СТАНДАРТОМ для всех будущих обзоров монет.
