==================================================
1. ГЛАВНЫЙ НОВЫЙ ЭЛЕМЕНТ — ENERGY DOT
==================================================

Добавь во все подходящие сцены специальный motion объект:

ENERGY_DOT

Это маленький яркий светящийся объект.

Он НЕ должен просто мигать.

Он должен ФИЗИЧЕСКИ ДВИГАТЬСЯ ПО ТРАЕКТОРИИ.

Например:

NODE A
   ↓
──────────────●────────────
               ↓
             NODE B

● = ENERGY_DOT

При движении:

- яркая точка
- сильный glow
- короткий световой хвост
- motion blur
- небольшой bloom
- trail
- короткий flash при достижении узла

Пример:

WALLET
   ↓
───────────────●──────────────→ DEX
                ✦
              glow

Точка должна двигаться:

START → PATH → NODE → PAUSE → NEXT PATH → NODE

НЕ использовать случайное движение.

Движение должно иметь смысл.

==================================================
2. LIGHT TRAIL
==================================================

За ENERGY_DOT должен оставаться короткий световой след.

Сделать:

- fading trail
- glow
- motion blur
- alpha decay

След не должен быть огромным.

Он должен выглядеть как:

"лазерная частица / энергия / сигнал".

Особенно красиво использовать при:

WALLET → DEX
DEX → TOKEN
WHALE → EXCHANGE
BUY → PRICE CHART
ACCUMULATION → TARGET

==================================================
3. СЕТКА
==================================================

Текущую сетку НЕ УБИРАТЬ.

Но сделать её:

- более резкой
- геометричной
- технической
- контрастной
- clean
- uniform
- crisp

НЕ делать мягкую blurry mesh.

Нужна настоящая:

TECHNICAL GRID

с четкими горизонтальными и вертикальными линиями.

Добавить несколько уровней:

BACKGROUND GRID
MID GRID
FOREGROUND GRID

Можно использовать легкую перспективу:

горизонтальные линии немного сходятся в глубину.

Сетка должна создавать ощущение пространства.

Она не должна просто быть фоном.

Она должна участвовать в композиции.

==================================================
4. GRID PARALLAX
==================================================

Добавить очень легкое движение сетки относительно камеры.

При camera push:

grid слегка движется назад.

При camera pull:

grid слегка меняет масштаб.

При horizontal camera movement:

grid получает небольшой parallax.

Очень аккуратно.

НЕ делать эффект "землетрясения".

Нужно ощущение настоящей глубины.

==================================================
5. LIGHT SWEEP
==================================================

Добавить редкие световые проходы по сцене.

Например:

───────────────
        ╲
         ╲
          ╲
───────────────

Световой луч проходит через grid.

При прохождении:

- grid кратковременно подсвечивается
- nodes получают glow
- текст может слегка реагировать
- появляется короткий bloom

Это должно ощущаться как scanner / intelligence system.

Использовать НЕ постоянно.

Только в ключевых моментах.

==================================================
6. NODE ANIMATION
==================================================

Все важные узлы должны иметь жизнь.

Например:

WALLET
DEX
ETH
EXCHANGE
BTC
USDC

Каждый node:

1. появляется
2. получает outline
3. слегка пульсирует
4. может быть подсвечен ENERGY_DOT
5. соединяется с другим node

При достижении ENERGY_DOT:

NODE:

scale 1.0
→ 1.08
→ 1.0

и короткий glow pulse.

==================================================
7. ЛИНИИ ДОЛЖНЫ РИСОВАТЬСЯ
==================================================

НЕ показывать готовую линию сразу.

Например:

WALLET ───────── DEX

Сначала:

WALLET

потом:

WALLET ──

потом:

WALLET ───────

потом:

WALLET ───────────── DEX

То есть линия должна "рисоваться".

Можно использовать:

stroke reveal
mask reveal
path animation

Это особенно важно для:

money flow
blockchain flow
transaction diagrams
timeline
wallet relationships

11. VISUAL MORPH
==================================================

Очень важно.

Следующий визуальный блок должен иногда
ПЕРЕХОДИТЬ из предыдущего.

Например:

wallet node
↓
node увеличивается
↓
превращается в круг
↓
круг становится coin
↓
coin превращается в chart point
↓
chart начинает двигаться.

Не:

SCENE 1
CUT
SCENE 2
CUT
SCENE 3

А:

OBJECT A
→ MORPH
→ OBJECT B
→ MORPH
→ OBJECT C

Это создаст профессиональное ощущение motion design.

13. BUY / SELL
==================================================

BUY:

ENERGY_DOT движется к TOKEN.

TOKEN получает glow.

BUY появляется через kinetic reveal.

SELL:

направление движения меняется.

TOKEN
↓
DEX / EXCHANGE

Energy trail движется обратно.

Цветовые акценты использовать только как semantic signal.

НЕ превращать видео в кислотный neon template.

==================================================

==================================================

НЕ ДЕЛАЙ ПРОСТО "БОЛЬШЕ АНИМАЦИЙ".

Мне нужен именно эффект:

"сцена ЖИВЁТ".

Когда зритель видит:

WALLET → DEX

он должен видеть,
как энергия физически движется от одного объекта к другому.

$18.4M

ETH должен появиться как объект внутри пространства.

Когда камера двигается:

сетка и объекты должны иметь глубину.

Когда появляется линия:

она должна рисоваться.

Когда ENERGY_DOT достигает node:

node должен реагировать.
