# 2. ПОСЛЕ НАЖАТИЯ «СОЗДАТЬ КОНТЕНТ»

Получить список выбранных каналов.

Для каждого выбранного канала запускать отдельную генерацию.

ВАЖНО:

Каждый канал должен получать **СВОЙ уникальный контент**.

Нельзя генерировать один сценарий и копировать его на другие каналы.

Для каждого канала отдельно создаются:

1. Идея.
2. Тема.
3. Формат.
4. Hook.
5. Сценарий.
6. Название.
7. SEO-описание.
8. Ключевые слова.
9. Теги.
10. Хэштеги.
11. Prompt для визуала.
12. Текст озвучки.

---

# 3. КОНТЕНТНАЯ ЛОГИКА

AI должен понимать, что разные каналы могут иметь разную направленность.

У каждого канала должна быть собственная конфигурация.

Минимальные параметры:

channel_name
category
niche
tone
topics
formats
video_length
hook_style
target_audience

Например:

Канал:

ЗНАКИ ВСЕЛЕННОЙ

Ниша:

* знаки зодиака
* судьба
* любовь
* деньги
* отношения
* мистические прогнозы
* знаки Вселенной

Tone:

* загадочный
* интригующий
* эмоциональный
* динамичный

Другой канал может иметь совершенно другую направленность.

Не предполагать, что все 15 каналов одинаковые.

---

# 4. ОТКУДА БЕРЁТСЯ ИДЕЯ

Создать отдельный CONTENT IDEA ENGINE.

AI может использовать три источника идей.

## Источник №1 — собственная генерация AI

AI самостоятельно придумывает новые идеи на основе:

* ниши канала;
* его тем;
* форматов;
* текущей даты;
* уже опубликованных роликов.

## Источник №2 — актуальные астрологические события

Если для проекта доступен web search, разрешить использовать актуальную информацию:

* фазы Луны;
* полнолуние;
* новолуние;
* затмения;
* астрологические события;
* текущие даты;
* другие актуальные события, связанные с астрологическим контентом.

Актуальные сведения использовать только после проверки источника.

## Источник №3 — внутренняя база идей

Создать возможность хранить категории:

* любовь;
* отношения;
* деньги;
* карьера;
* судьба;
* совместимость;
* характер;
* предупреждения;
* удача;
* Луна;
* знаки Вселенной;
* мистика;
* конкретные знаки зодиака.

AI должен комбинировать:

ТЕМА + ФОРМАТ + ЗНАК/ЗНАКИ + HOOK

чтобы получать новые идеи.

# 5. ПРИМЕРЫ ФОРМАТОВ

Создать базовую библиотеку форматов.

Например:

1. «3 знака зодиака, которым...»
2. «Эти знаки скоро...»
3. «Если ты родился под этим знаком...»
4. «Вселенная предупреждает...»
5. «Кому скоро повезёт...»
6. «Что ждёт этот знак...»
7. «Эти знаки встретят...»
8. «Не игнорируй этот знак...»
9. «Почему именно эти знаки...»
10. «Что изменится в жизни...»
11. «Кто скоро встретит любовь...»
12. «Кому улыбнётся финансовая удача...»
13. «Какие знаки подходят друг другу...»
14. «Секрет характера этого знака...»
15. «Знак Вселенной для тебя...»

Но библиотека должна быть расширяемой.

AI должен чередовать форматы.

Не использовать постоянно один и тот же шаблон.

---

# 6. АНТИПОВТОР

Это КРИТИЧЕСКИ ВАЖНО.

Перед генерацией нового контента система должна проверить уже созданный контент.

Проверять:

* тему;
* идею;
* заголовок;
* hook;
* сценарий;
* формат.

Проверять не только внутри одного канала, но и среди других каналов категории Horoscope.

Если новая идея слишком похожа на предыдущую — отклонить её и попросить AI создать новую.

Создать content_hash или другой механизм определения практически одинакового контента.

Не допускать простого перефразирования старого сценария.

---

# 7. ГЕНЕРАЦИЯ СЦЕНАРИЯ

После выбора идеи AI создаёт сценарий Shorts.

Структура:

HOOK
↓
ИНТРИГА
↓
ОСНОВНАЯ ЧАСТЬ
↓
ФИНАЛЬНАЯ МЫСЛЬ

Ориентировочная длительность:

30–45 секунд.

Но длительность должна зависеть от настроек конкретного канала.

Текст должен быть пригоден для TTS.

Требования:

* короткие предложения;
* естественная речь;
* динамичное начало;
* отсутствие длинного вступления;
* никаких фраз типа «в этом видео мы расскажем...»;
* сразу переходить к сути.

---

# 8. HOOK

AI должен создавать отдельный Hook.

Hook должен заинтересовать пользователя в первые секунды.

Типы Hook:

* интрига;
* предупреждение;
* неожиданность;
* вопрос;
* обещание;
* загадка.

Не использовать одинаковые Hooks подряд.

---

# 9. НАЗВАНИЕ SHORTS

После создания сценария отдельный SEO TITLE ENGINE создаёт название.

Название должно:

* соответствовать сценарию;
* быть коротким;
* быть понятным;
* содержать релевантную поисковую фразу;
* вызывать интерес;
* не быть кликбейтом, который не соответствует содержанию.

Создавать 3 варианта.

Например:

1. «Эти 3 знака скоро встретят любовь ❤️»
2. «3 знака зодиака, которым повезёт в любви»
3. «Кто встретит любовь уже совсем скоро? ❤️»

Затем AI выбирает наиболее подходящий вариант согласно правилам проекта.

---

# 10. SEO DESCRIPTION ENGINE

Для каждого ролика создавать индивидуальное описание.

Описание должно основываться именно на содержании текущего ролика.

Не использовать одинаковое описание для всех Shorts.

Описание должно содержать естественные релевантные поисковые фразы.

---

# 11. KEYWORDS ENGINE

Создавать индивидуальный набор ключевых слов.

Например для любовного ролика:

гороскоп, знаки зодиака, любовный гороскоп, любовь, отношения, астрология, совместимость

Для денежного ролика:

гороскоп, знаки зодиака, деньги, финансовый гороскоп, финансовая удача, астрология

Для лунного ролика:

лунный прогноз, полнолуние, луна, знаки зодиака, астрология, гороскоп

Ключевые слова должны соответствовать конкретному видео.

Не использовать нерелевантные ключи.

---

# 12. TAGS ENGINE

Генерировать отдельный набор YouTube-тегов.

Например:

гороскоп, знаки зодиака, астрология, гороскоп 2026, любовный гороскоп, отношения, любовь

Количество тегов сделать настраиваемым.

# 13. HASHTAGS ENGINE

Хэштеги должны соответствовать ролику.

# 14. VISUAL ENGINE

Создать отдельный модуль, который на основании готового сценария решает, какой визуал нужен.

На первом этапе поддержать два типа:

STOCK
AI_IMAGE

В будущем можно добавить:

AI_VIDEO

---

# 15. STOCK VISUAL

Если выбран STOCK:

AI создаёт поисковые запросы для стокового видео.

Например сценарий про любовь:

romantic couple
love relationship
couple walking
romantic night

Сценарий про Луну:

full moon
night sky
moonlight
stars

Сценарий про деньги:

money
business
success
wealth

Поисковые запросы должны создаваться индивидуально под сценарий.

Архитектуру сделать так, чтобы позже можно было подключить API стоковых видеосервисов.

---

# 16. AI VISUAL

Если выбран AI_IMAGE:

AI создаёт подробный prompt для генерации вертикального изображения.

Prompt должен учитывать:

* содержание;
* знак зодиака;
* атмосферу;
* цветовую атмосферу;
* композицию;
* вертикальный формат 9:16;
* отсутствие лишнего текста на изображении.

Например:

cinematic mystical night sky, full moon, glowing zodiac constellation, mysterious atmosphere, cinematic lighting, vertical composition, 9:16

Prompt должен быть уникальным для конкретного ролика.

---
