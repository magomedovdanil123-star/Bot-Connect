Нужно переделать логику HOROSCOPE так, чтобы кнопка:

🔮 СОЗДАТЬ ГОРОСКОП НА СЕГОДНЯ

создавала контент СРАЗУ ДЛЯ ВСЕХ выбранных YouTube-каналов.

Главная задача: AI должен работать как единый редактор всей сетки каналов, а не создавать одинаковые гороскопы для каждого канала.

1. У КАЖДОГО КАНАЛА — 3 СОБСТВЕННЫХ ФОРМАТА

Для каждого Horoscope-канала создай 3 характерных формата.

Например:

Канал «Гороскоп на завтра»:

Формат 1 — «Что ждёт знак завтра»
Формат 2 — «Главное предупреждение»
Формат 3 — «Неожиданное событие завтра»

Канал «Любовь по Знакам»:

Формат 1 — «Кто думает о тебе»
Формат 2 — «Человек из прошлого»
Формат 3 — «Неожиданное признание»

Канал «Деньги и Знаки»:

Формат 1 — «Денежный шанс»
Формат 2 — «Финансовое предупреждение»
Формат 3 — «Неожиданная возможность»

И так далее для ВСЕХ каналов.

Форматы должны соответствовать конкретной тематике канала.

Не используй один набор из 3 форматов для всех каналов.

2. AI ДОЛЖЕН ЧЕРЕДОВАТЬ 3 ФОРМАТА

При каждом запуске «Создать гороскоп на сегодня» AI анализирует историю канала.

Если в прошлый раз использовался:

Формат 1

то сегодня желательно использовать Формат 2 или 3.

Если Формат 2 использовался недавно — выбрать Формат 3 или 1.

Не допускать постоянного использования одного формата подряд.

При этом не нужно механически делать:

1 → 2 → 3 → 1 → 2 → 3.

AI должен учитывать историю и самостоятельно выбирать наиболее подходящий формат.

3. ВСЕ КАНАЛЫ ПЛАНИРУЮТСЯ ОДНОВРЕМЕННО

Это КРИТИЧЕСКИ ВАЖНО.

Когда пользователь выбирает 15 каналов и нажимает:

🔮 СОЗДАТЬ ГОРОСКОП НА СЕГОДНЯ

сначала AI должен получить информацию ОБО ВСЕХ 15 КАНАЛАХ одновременно.

После этого он распределяет:

* знак;
* формат;
* тему;
* подтему;
* angle;
* hook;
* эмоциональную подачу.

Только после создания общего Content Plan начинаем создавать отдельные сценарии.

Нельзя планировать канал №1, затем отдельно канал №2, затем отдельно канал №3.

Сначала:

15 каналов
↓
GLOBAL CONTENT PLAN
↓
15 уникальных идей
↓
сценарии

4. КАЖДЫЙ РОЛИК ДОЛЖЕН ОТЛИЧАТЬСЯ

Для каждого канала AI должен самостоятельно выбрать комбинацию:

CHANNEL
+
FORMAT
+
ZODIAC SIGN
+
TOPIC
+
SUBTOPIC
+
ANGLE
+
HOOK
+
EMOTIONAL STYLE

Например:

Канал 1:
Дева + деньги + неожиданный возврат + интрига

Канал 2:
Лев + любовь + человек из прошлого + эмоциональный hook

Канал 3:
Рыбы + работа + важное решение + предупреждение

Канал 4:
Скорпион + встреча + неожиданное знакомство + любопытство

и т.д.

НЕ делать:

Дева → деньги
Телец → деньги
Овен → деньги
Лев → деньги

если это выглядит как один и тот же ролик с заменой знака.

5. ЗНАКИ НЕ ПРИВЯЗАНЫ К КАНАЛАМ

Сегодня:

Канал 1 → Дева

Завтра:

Канал 1 → Рыбы

Послезавтра:

Канал 1 → Лев

AI выбирает знак динамически.

Учитывать историю, чтобы один знак не повторялся постоянно на одном канале.

6. ТЕМЫ AI ПРИДУМЫВАЕТ САМ

При нажатии «Создать гороскоп на сегодня» пользователь НЕ вводит тему.

AI получает:

CURRENT_DATE
CURRENT_DAY
CURRENT_MONTH
CURRENT_YEAR
CURRENT_TIMEZONE

и самостоятельно придумывает актуальные темы для каждого канала.

Темы должны соответствовать ДНК конкретного канала.

Например канал «Деньги и Знаки»:

* неожиданный денежный шанс;
* предложение по работе;
* возврат денег;
* финансовая ошибка;
* возможность дополнительного дохода;
* важное решение;
* неожиданные расходы.

AI может придумывать новые подтемы, а не ограничиваться этим списком.

7. АКТУАЛЬНОСТЬ

Использовать РЕАЛЬНУЮ текущую дату приложения.

Не использовать захардкоженную дату.

Передавать AI:

CURRENT_DATE
CURRENT_DAY
CURRENT_MONTH
CURRENT_YEAR
CURRENT_TIME
CURRENT_TIMEZONE

Контент должен создаваться именно на текущий день.

8. У КАЖДОГО РОЛИКА СВОЙ HOOK

Hook не должен быть одинаковым для всех каналов.

AI выбирает hook на основе:

канала
+
формата
+
темы
+
знака
+
угла подачи.

Не использовать один глобальный шаблон.

Сохраняем обязательное начало:

«Вы нашли это видео [АКТУАЛЬНАЯ ДАТА], и это не просто так…»

Но продолжение после этой фразы должно быть уникальным.

9. СТИЛЬ КАЖДОГО КАНАЛА

Каждый канал должен иметь собственный:

* tone of voice;
* стиль;
* эмоциональность;
* структуру;
* тип hooks;
* форматы;
* тематику.

Сценарий канала «Любовь по Знакам» не должен звучать так же, как сценарий «Деньги и Знаки».

10. ГЛОБАЛЬНАЯ ПРОВЕРКА ПЕРЕД ГЕНЕРАЦИЕЙ

После того как AI придумал все идеи, он должен проверить их МЕЖДУ СОБОЙ.

Проверить:

* одинаковые темы;
* одинаковые подтемы;
* одинаковые форматы;
* одинаковые hooks;
* одинаковые сюжеты;
* одинаковую структуру;
* слишком похожие идеи.

Если два ролика слишком похожи — AI должен изменить один из них ДО генерации сценариев.

11. SEO ДЛЯ КАЖДОГО РОЛИКА

После создания сценария AI автоматически генерирует индивидуальное SEO.

Для КАЖДОГО видео отдельно:

TITLE_VARIANTS — минимум 3 варианта
SELECTED_TITLE — лучший вариант
DESCRIPTION
KEYWORDS
TAGS
HASHTAGS

SEO должно учитывать:

* канал;
* его аудиторию;
* знак;
* тему;
* подтему;
* формат;
* hook;
* содержание сценария;
* текущую дату;
* поисковые запросы.

12. ЗАГОЛОВОК

Заголовок должен быть:

* кликабельным;
* интригующим;
* конкретным;
* соответствовать содержанию;
* не выглядеть как шаблон.

Не делать постоянно:

«Гороскоп Девы на сегодня»

AI должен придумывать более сильные варианты, например:

«ДЕВА, НЕ ИГНОРИРУЙ ЭТО СЕГОДНЯ — ВСЁ НАЧНЁТСЯ С ОДНОГО РАЗГОВОРА»

Но заголовок всегда должен соответствовать реальному содержанию ролика.

13. DESCRIPTION

Для каждого видео отдельное описание.

Не копировать описание между каналами.

Описание должно естественно содержать релевантные поисковые фразы и отражать содержание конкретного ролика.

14. KEYWORDS / TAGS / HASHTAGS

Для каждого видео генерировать отдельно.

Не использовать один глобальный набор.

Учитывать:

* знак;
* тему;
* подтему;
* формат;
* поисковый интент;
* long-tail запросы;
* специфику канала.

15. ИТОГОВЫЙ CONTENT PLAN

До генерации сценариев AI должен создать примерно такую структуру:

CHANNEL
FORMAT
ZODIAC
TOPIC
SUBTOPIC
ANGLE
HOOK
EMOTIONAL_TONE

Для всех выбранных каналов одновременно.

После проверки уникальности каждый item передаётся дальше в существующий Script Generator.

16. НЕ ЛОМАТЬ СУЩЕСТВУЮЩУЮ СИСТЕМУ

Не менять:

* Telegram UI;
* video generation;
* ElevenLabs;
* music;
* stock media;
* NOX banner;
* MP4 rendering;
* Telegram review;
* YouTube publication.

Меняем только интеллектуальную часть:

GLOBAL CONTENT PLANNER
+
CHANNEL FORMATS
+
TOPIC SELECTION
+
HOOK SELECTION
+
ANTI-REPEAT
+
SCRIPT INPUT
+
SEO GENERATION.

Сначала изучи текущую реализацию и используй существующие функции и таблицы там, где это возможно.

Не создавай дублирующую архитектуру без необходимости.

После реализации покажи тестовый пример для 5 выбранных каналов, чтобы было видно, что AI действительно создал разные:

* форматы;
* знаки;
* темы;
* hooks;
* angles;
* стили;
* titles;
* descriptions;
* keywords;
* tags;
* hashtags.
