Я загрузил тебе видео-референс.

Я ХОЧУ, ЧТОБЫ ТЕКУЩИЙ РЕНДЕРЕР ПОВТОРЯЛ ИМЕННО ПРИНЦИП МОНТАЖА ЭТОГО РЕФЕРЕНСА.

НЕ ПЕРЕПИСЫВАЙ ТЕКУЩУЮ СИСТЕМУ.

НЕ УБИРАЙ ТО, ЧТО УЖЕ РАБОТАЕТ.

Нужно точечно изменить именно VISUAL COMPOSITION + TIMING + MONTAGE.

В РЕФЕРЕНСЕ РАБОТАЮТ 3 СЛОЯ:

1. ВЕДУЩИЙ В НИЖНЕЙ ЧАСТИ
2. ДИНАМИЧНЫЕ ТЕМАТИЧЕСКИЕ ВИЗУАЛЫ В ВЕРХНЕЙ ЧАСТИ
3. КИНЕТИЧЕСКИЙ ТЕКСТ МЕЖДУ НИМИ

Именно эту архитектуру нужно сохранить.

========================================

1. ВЕДУЩИЙ

Ведущий находится в нижней части кадра.

Он НЕ должен быть полностью статичным.

Используй существующие pose/character возможности.

При переходе между смысловыми блоками:

* меняй позу;
* меняй жест;
* меняй положение рук;
* меняй выражение лица;
* иногда меняй горизонтальное положение.

Не менять позу каждую секунду.

Ориентир:
примерно каждые 3–6 секунд или при смене смыслового блока.

========================================

2. ВЕРХНЯЯ ЗОНА — ГЛАВНОЕ

Верхняя половина кадра должна постоянно меняться.

Новый визуальный элемент примерно каждые 1–3 секунды.

Это может быть:

* sticker;
* illustration;
* PNG object;
* screenshot;
* UI card;
* chart;
* number;
* icon;
* diagram;
* photo;
* document;
* notification;
* financial interface;
* animated graph;
* comparison card.

НЕ держать одну картинку 7–10 секунд.

========================================

3. ВИЗУАЛЫ ДОЛЖНЫ ПОЯВЛЯТЬСЯ БЫСТРО

НЕ делать:

fade in 1–2 секунды.

Использовать короткие динамичные entrance animations:

* pop;
* scale + overshoot;
* slide;
* swipe;
* spring;
* bounce;
* rotate + scale;
* fly-in;
* sticker pop;
* card snap.

Ориентировочная длительность появления:
примерно 150–500 ms.

Сам визуал после появления может оставаться дольше.

========================================

4. ВАЖНО: ВИЗУАЛ = СМЫСЛ ОЗВУЧКИ

Перед рендером раздели voice script на смысловые фрагменты.

Для каждого фрагмента определить:

VOICE
↓
KEYWORD
↓
VISUAL

Например:

VOICE:
«Облигация — это долговая ценная бумага.»

VISUAL:
стикер облигации + документ + слово «ДОЛГ».

VOICE:
«Ты даёшь деньги компании.»

VISUAL:
инвестор → 10 000 ₽ → компания.

VOICE:
«Взамен получаешь купон.»

VISUAL:
карточка «КУПОН 18%» + монеты.

То есть визуал должен буквально помогать понять сказанное.

========================================

5. НЕ ИСПОЛЬЗОВАТЬ ОДИН ШАБЛОН ВИЗУАЛОВ

КРИТИЧНО.

Если тема:

«Что такое облигация?»

использовать:

bond / issuer / investor / coupon / yield / maturity / money flow.

Если:

«Что такое акция?»

использовать:

company / shares / ownership / stock / price / chart / investors.

Если:

«Что такое паевой фонд?»

использовать:

many investors / common fund / portfolio / stocks / bonds / gold / assets / fund chart.

Если:

«Что такое дивиденды?»

использовать:

company profit / distribution / shareholders / payment / dividend.

Визуальная история должна определяться ТЕМОЙ.

========================================

6. МОНТАЖ

Референс ощущается быстрым не потому, что камера постоянно летает.

Он ощущается быстрым потому, что:

НОВЫЙ ВИЗУАЛ
→
НОВЫЙ ВИЗУАЛ
→
НОВЫЙ ВИЗУАЛ
→
НОВАЯ ПОЗА
→
НОВЫЙ ТЕКСТ
→
НОВАЯ КАРТОЧКА
→
НОВЫЙ STICKER.

Именно это нужно воспроизвести.

Средний visual beat:
примерно 1–3 секунды.

Не обязательно полностью менять сцену.

Можно заменить только верхний объект.

========================================

7. КОМПОЗИЦИЯ

Базовая композиция:

ВЕРХ:
visual assets

СЕРЕДИНА:
kinetic text / keywords

НИЗ:
host

Но верхние элементы должны менять:

* размер;
* положение;
* сторону;
* композицию.

Например:

visual сверху по центру

→ следующий справа

→ следующий слева

→ два маленьких рядом

→ большая карточка

→ screenshot

→ sticker.

Не держать все объекты всегда по центру.

========================================

8. ТЕКСТ

Не превращать текст в обычные субтитры.

Нужны короткие крупные смысловые фразы.

Например:

«ДОЛГОВАЯ БУМАГА»

«10 000 ₽»

«18%»

«КУПОН»

«1 ГОД»

«ДОЛЯ КОМПАНИИ»

Ключевое слово может:

* появиться крупно;
* выделиться;
* изменить размер;
* получить underline;
* pop;
* slide.

========================================

9. ПОВТОРИТЬ ИМЕННО ОЩУЩЕНИЕ РЕФЕРЕНСА

Главное ощущение:

Ведущий спокойно объясняет.

А вокруг него постоянно появляются маленькие визуальные доказательства того, что он сейчас говорит.

Это НЕ полноценная презентация.

Это НЕ статичный инфографический ролик.

Это НЕ один большой animated scene.

Это:

**HOST + RAPID VISUAL INSERTS + KINETIC TEXT + QUICK TRANSITIONS.**

========================================

10. ТЕСТ

Сделай один тестовый ролик:

«Что такое облигация?»

Продолжительность 30–40 секунд.

За эти 30–40 секунд должно быть примерно:

10–20 визуальных beats.

Несколько разных stickers/cards/images.

Несколько смен позы ведущего.

Короткие kinetic text elements.

Все визуалы должны быть непосредственно связаны с тем, что произносится.

После этого покажи результат.

НЕ делай пока 5–10 роликов.

Сначала добейся того, чтобы ОДИН ролик визуально был близок к принципу референса.
