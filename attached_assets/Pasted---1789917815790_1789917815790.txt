* какие знаки зодиака недавно использовались;

5. Для каждого канала AI должен самостоятельно выбрать комбинацию:

CHANNEL + ZODIAC SIGN + TOPIC + FORMAT + ANGLE

Например:

Канал 1:
Дева + деньги + предупреждение + финансовая ошибка сегодня

Канал 2:
Лев + любовь + неожиданное событие + человек из прошлого

Канал 3:
Рыбы + работа + 3 признака + новая возможность

Канал 4:
Скорпион + отношения + важный разговор + неожиданное решение

И так далее для ВСЕХ выбранных каналов.

ВАЖНО:

15 каналов = 15 разных контентных концепций.

Нельзя брать одну тему и просто менять знак зодиака.

AI должен самостоятельно распределять темы таким образом, чтобы контент между каналами был максимально разнообразным.

АНТИ-ПОВТОР:

Проверять историю ВСЕХ horoscope-каналов, а не только конкретного канала.

Нельзя повторять или почти повторять:

* тему;
* знак + тему;
* основную идею;
* формат;
* угол подачи;
* hook;
* структуру;
* сценарий.

Простая замена нескольких слов не считается новым контентом.

AI должен учитывать семантическое сходство.

Если новая концепция слишком похожа на уже существующий контент, она должна быть отклонена и придумана заново.

РАВНОМЕРНОСТЬ:

Planner должен стремиться равномерно распределять:

* знаки зодиака;
* темы;
* форматы;
* углы подачи.

При этом не нужно механически распределять всё по кругу.

AI должен выбирать наиболее интересную комбинацию с учётом истории конкретного канала.

ВАЖНО:

Не нужно навсегда закреплять один знак за одним каналом.

Например, сегодня Канал 1 может получить Деву, завтра — Рыбы, послезавтра — Льва.

Знак должен быть переменной частью контент-плана.

ТОЖЕ САМОЕ С ТЕМАМИ.

Если канал вчера получил «любовь», сегодня желательно предложить ему другую смысловую категорию, если нет причины повторять любовь.

ИНТЕЛЛЕКТУАЛЬНЫЙ ВЫБОР:

AI не должен просто случайно выбирать значения из списков.

Он должен рассуждать по следующему принципу:

1. Что уже выходило?
2. Что недавно использовалось?
3. Какие комбинации уже были?
4. Какие комбинации слишком похожи?
5. Какие темы сейчас недостаточно представлены?
6. Как разнообразить сегодняшние ролики?
7. Какая комбинация лучше подходит конкретному каналу?
8. Как сделать сегодняшний набор из всех каналов разнообразным?

И только после этого сформировать окончательный план.

Если два канала получили слишком похожие концепции — заменить одну из них.

НЕ ДЕЛАТЬ:

Не спрашивать пользователя:

«Введите тему»

«Какую тему использовать?»

«Какой знак выбрать?»

«Что создать для канала?»

Если пользователь нажал «🔮 ГОРОСКОП НА СЕГОДНЯ», AI сам принимает эти решения.

РУЧНОЙ РЕЖИМ:

При этом не удалять возможность ручной генерации.

Должны существовать два режима:

🔮 ГОРОСКОП НА СЕГОДНЯ
— AI сам придумывает и распределяет контент.

✏️ СОЗДАТЬ ПО ТЕМЕ
— пользователь вручную задаёт тему.

По умолчанию кнопка «ГОРОСКОП НА СЕГОДНЯ» должна использовать интеллектуальный Content Planner.

ВАЖНО ПО АРХИТЕКТУРЕ:

Не переписывай существующий рабочий код без необходимости.

Сначала изучи текущую реализацию модуля horoscope.

Найди существующую логику, где бот запрашивает у пользователя тему.

Заменить именно эту логику для режима «ГОРОСКОП НА СЕГОДНЯ» на Content Planner.

Не ломать существующие кнопки, каналы, базу данных и генерацию контента.

Если необходимые поля уже существуют в БД — использовать их.

Если не существуют — добавить минимально необходимые поля/таблицы.

После реализации проверить:

1. Нажатие «🔮 ГОРОСКОП НА СЕГОДНЯ».
2. Выбор нескольких каналов.
3. Автоматическое создание индивидуального плана.
4. Отсутствие запроса темы у пользователя.
5. Разные темы для разных каналов.
6. Разные знаки.
7. Разные форматы.
8. Проверку истории.
9. Проверку повторов между всеми каналами.
10. Только после этого запуск генерации отдельных сценариев.

ПОЛЬЗОВАТЕЛЬ ВЫБИРАЕТ КАНАЛЫ.
