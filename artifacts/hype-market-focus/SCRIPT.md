# «Монета в фокусе»: HYPE

## Режиссёрская экспликация

- **Тезис:** за последний месяц HYPE обогнал BTC и ETH по доходности. Новости о займах держателям и листинге Binance — возможные факторы, не доказанная причина; рекорд открытого интереса показывает активность позиций, а не гарантирует продолжение.
- **Формат и длительность:** YouTube Shorts, 9:16, 44 секунды.
- **Визуальная идентичность:** независимая редакционная графика рыночного терминала — почти чёрный графит, холодная белая типографика, кислотно-зелёный цвет для положительных данных и красный только для снижения/риска. Space Grotesk для крупных чисел, JetBrains Mono для подписей и источников. Это не официальная палитра Hyperliquid; логотип не используется.
- **Герой:** реальная ценовая траектория HYPE и её последняя точка; тонкое металлическое кольцо — носитель переходов, не изображение фирменного знака.
- **Монтаж:** крупная типографика с жёсткими пружинными ударами; линия цены строится из зафиксированных точек; короткие масочные/перспективные переходы с непрерывным круглым носителем.
- **Дуга:** месячный рост → пик и откат → возможные новостные факторы и рекорд открытого интереса → сравнение с BTC/ETH → расчёт с отделённой прибылью → условный сценарий и CTA.
- **Финал:** вместо ещё одной диаграммы — инверсия на светлое поле и короткий редакционный вывод. Последнее кольцо совпадает с кольцом первого кадра для бесшовного цикла.
- **Звук:** оригинальный инструментальный слой; поверх него — естественная русская озвучка тем же голосом во всех шести сценах. Музыка приглушена под речь и сведена с голосом в один 44-секундный трек для точной синхронизации. Без SFX и без заявления о beat-sync.
