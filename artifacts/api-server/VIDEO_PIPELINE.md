# Finance Long motion pipeline

This pipeline applies only to Telegram's **ФИНАНСЫ → Обзор монеты + свой сценарий** route.

1. **Script analysis:** preserve the supplied narration verbatim. Divide its ideas by meaning, causal links, stated figures, and transitions; do not split mechanically by sentence.
2. **Scene map:** plan duration, thesis, visual metaphor, primary and secondary forms, motion, and the handoff to the next scene. Verified coin data is visual context only.
3. **Storyboard:** give every scene 5–8 ordered visual events on its final `MOTION_SEQUENCE:` line. Use the tagged event library in `MOTION_DESIGN_SYSTEM.md`.
4. **Visual design:** use the fixed palette, Montserrat ExtraBold, 16:9 composition, and a lower caption band. Keep visual labels and numbers sourced.
5. **Motion design:** plan entrance, build, interaction, micro-motion, exit, and transition using the documented motion tokens.
6. **Voice preparation:** generate the scene voice from the unchanged author text before showing the storyboard. Do not render video at this stage.
7. **Quality control:** check sequence validity, composition, depth, hierarchy, detail, palette, typography, and caption clearance.
8. **Continuity:** review each scene with its previous and next scenes; preserve visual continuity without repeating the same composition.
9. **Approval and final render:** show the static concept and script in Telegram. Start the final render only after the user explicitly approves the storyboard.
